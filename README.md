# 데이터 과학 웹교과서

2022 개정 교육과정 고등학교 진로 선택 과목 **‘데이터 과학’** 학습용 인터랙티브 웹교과서입니다.
4개 영역 · 19차시 · **성취기준 19개를 모두** 다루며, **직접 값을 바꿔 보는 그래프**와
**브라우저에서 실행되는 파이썬 코드**를 중심으로 구성했습니다.

교과서 출판사가 아니라 **성취기준이 뼈대**입니다. 모든 차시는 성취기준 코드에 연결되어 있고,
학교가 어느 교과서를 쓰든 해당 단원을 찾아갈 수 있도록 3사 대조표를 함께 제공합니다.

## 구성

| 구성 | 수량 |
|---|---|
| 영역(단원) | 4개 — 교육과정 영역 구분 그대로 |
| 차시 | **19쪽** (성취기준 1개 = 차시 1개) |
| 성취기준 | **19개 전부** (연결 누락 0) |
| 그래프 | **19개** — 산점도·꺾은선·막대·히스토그램·상자그림 |
| 파이썬 실행 블록 | **20개** (오프라인일 때는 예상 출력 표시) |
| 확인 문제 | **76문항** (객관식 + OX, 즉시 채점·해설) |
| 용어 정의 | **61개** (본문 툴팁 + 용어집) |
| 표 · 삽화 자리 | 46 · 11 |

| 영역 | 성취기준 | 차시 | 주요 활동 |
|---|---|---|---|
| **Ⅰ. 데이터 과학의 이해** | 12데과01-01 ~ 01-04 | 4차시 | 데이터 기반 의사 결정, 정형·비정형과 속성의 가치, 데이터셋 통합, 사회 변화와 진로 |
| **Ⅱ. 데이터 준비와 분석** | 12데과02-01 ~ 02-04 | 4차시 | 표집 편향, 이상치·결측치·정규화, 상관관계와 인과관계, 같은 데이터 다른 결론 |
| **Ⅲ. 데이터 모델링과 평가** | 12데과03-01 ~ 03-06 | 6차시 | 최소제곱법 vs 경사하강법, k-평균 군집, 지지도·신뢰도·향상도, 오차 지표와 정확도 |
| **Ⅳ. 데이터 과학 프로젝트** | 12데과04-01 ~ 04-05 | 5차시 | 주제 적합성 판단, 탐색적 데이터 분석(EDA), 2개 이상 방법 비교, 성찰과 사회적 영향 |

## 학습자용 기능

- **3단 화면** — 좌측 단원 트리 / 본문 / 우측 목차(현재 위치 자동 표시)
- **성취기준으로 찾기** — 본문 검색과 함께 `12데과03-04` 같은 코드를 그대로 넣어 찾을 수 있습니다
- **교과서 대조표** — YBM·씨마스·천재 3사의 해당 단원을 나란히 표시
- **그래프** — 색과 글꼴이 화면 테마를 따라가고, 모든 그래프에 **데이터 표**가 함께 있어
  화면 낭독기로도 읽을 수 있습니다
- **파이썬 실행** — 첫 실행 때만 환경을 내려받습니다. 학교망에서 막히면 예상 출력을 보여 줍니다
- **밝은/어두운 화면**, **읽은 차시 표시**, **인쇄** 지원

## 만들기와 실행

```bash
cd site
npm install
npm run dev      # 개발 서버
npm run build    # site/dist/ 에 정적 파일 25쪽 생성
python serve.py  # 만들어진 파일을 파이썬만으로 열기 (학교 전산실·USB 배포용)
```

## 검증

```bash
python scripts/validate.py     # 성취기준 매핑·스키마·[확인필요] 검사
node site/test/chart.test.mjs      # 그래프 모듈 22개 검사
node site/test/pyrunner.test.mjs   # 파이썬 실행기 24개 검사 (오프라인 폴백 포함)
```

현재 상태: 성취기준 커버리지 **19/19**, 오류 0, 경고 0.

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `content/` | **콘텐츠의 원본.** 교육과정·출판사 대조표·차시 19개 (JSON) |
| `site/` | 웹 사이트 (Astro). 본문 렌더러 하나가 모든 차시를 그립니다 |
| `scripts/validate.py` | 콘텐츠 검증 |
| `docs/` | 설계 계획서, 레퍼런스 분석, 검증 리포트 |
| `CLAUDE.md` | 집필·개발 규칙 |

출판사 교과서·지도서 원본은 저작물이므로 이 저장소에 포함하지 않습니다.
